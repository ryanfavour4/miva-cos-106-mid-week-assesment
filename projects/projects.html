Study Companion

Completed

A browser-based study planner that helps students organise assignments by subject and due date. Tasks persist between sessions using the browser's localStorage, so nothing is lost on refresh. Built entirely with vanilla JavaScript — no frameworks, no build tools.

HTML5 CSS3 JavaScript localStorage Responsive Design

Key features

  • Add, complete, and delete tasks dynamically
  • Real-time task statistics (total, completed, remaining)
  • Optional subject tags and due dates
  • Data persists across page reloads
